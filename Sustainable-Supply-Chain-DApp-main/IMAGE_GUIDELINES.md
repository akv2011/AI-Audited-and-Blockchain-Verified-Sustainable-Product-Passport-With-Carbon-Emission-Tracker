# Walmart Supply Chain DApp - Image Guidelines

## Image Usage Guidelines for Walmart Project

### 1. Logo Usage
- **Primary Logo**: Use the official Walmart logo for main branding
- **Size Requirements**: Minimum 100px width, maximum 300px for headers
- **Background**: Use on white or dark blue backgrounds for best contrast
- **File Format**: PNG with transparent background preferred

### 2. Sustainability Images
- Focus on green technology, renewable energy, and supply chain transparency
- Use images that reflect Walmart's commitment to Project Gigaton
- Preferred dimensions: 16:9 aspect ratio for hero images
- Resolution: Minimum 1200px width for web display

### 3. Technology Illustrations
- Blockchain and data visualization themes
- Modern, clean design aesthetic
- Colors should align with Walmart brand palette
- Use icons from Font Awesome or similar libraries for consistency

### 4. Responsive Design
- Provide multiple image sizes for different screen resolutions
- Use WebP format where supported for better performance
- Implement lazy loading for better page performance

### 5. Accessibility
- All images must include descriptive alt text
- Ensure sufficient color contrast for visually impaired users
- Use semantic HTML structure for screen readers

### 6. File Organization
```
public/images/
├── logos/
│   ├── walmart-logo.png
│   ├── walmart-icon.ico
│   └── partner-logos/
├── backgrounds/
│   ├── hero-sustainability.jpg
│   ├── dashboard-bg.jpg
│   └── supply-chain-network.jpg
├── icons/
│   ├── carbon-footprint.svg
│   ├── supply-chain.svg
│   ├── blockchain.svg
│   └── sustainability.svg
└── placeholders/
    ├── product-placeholder.jpg
    └── loading-spinner.gif
```

### 7. Performance Optimization
- Compress images using tools like TinyPNG or ImageOptim
- Use appropriate file formats (JPEG for photos, PNG for logos/icons, SVG for simple graphics)
- Implement responsive images with srcset attributes
- Consider using a CDN for faster image delivery

### 8. Brand Compliance
- All images must align with Walmart's brand guidelines
- Use official Walmart colors: #0071ce (blue), #ffc220 (yellow)
- Maintain consistent visual style throughout the application
- Obtain proper permissions for any third-party images

### 9. Sustainability Focus
- Highlight renewable energy initiatives
- Show supply chain transparency and traceability
- Emphasize environmental impact reduction
- Include diversity and social responsibility imagery

### 10. Legal Considerations
- Ensure all images are properly licensed
- Include proper attribution where required
- Avoid using copyrighted material without permission
- Use royalty-free or Creative Commons licensed images when possible
